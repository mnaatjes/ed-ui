# Architecture Documentation & Governance Index

This directory serves as the maintainer-facing architectural ledger and Single Source of Truth (SSoT) for `ed-ui`, governed by the Unified Process dual-root documentation boundary.

## Taxonomy & Structure

- **`architecture/adr/`:** Architectural Decision Records (MADR 3.0 immutable records).
- **`architecture/designs/`:** Software Design Documents (IEEE 1016 / Google Design Docs).
- **`architecture/use-cases/`:** RUP Functional Use-Case Specifications.
- **`architecture/risk/`:** Master Risk Register ($RE = P \times I$).
- **`architecture/rfcs/`:** Collaborative Engineering Proposals.
- **`architecture/api/`:** Boundary Interface Contracts (OpenAPI 3.1 / AsyncAPI).
